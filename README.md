# 阙下归人

**[▶ 点击开始游戏](https://tianjiaqi888.github.io/que-xia-gui-ren/)**

无需下载安装，打开链接即可游玩。

一款围绕四川渠县汉阙与冯焕故事展开的二维叙事解谜游戏。

一场旅途中的梦，把你带进陌生的墓室。火光照见石壁，也照见一位忘记了自己是谁的男子。你需要寻找散落的线索，走进器物留下的往事，慢慢认出眼前这个人。

他的故事里有征战、为官与寻常生活，也有没能说完的话。游戏想让人记住的，是这些经历中的选择，以及他与家人、百姓之间的牵挂。

## 怎样游玩

故事共八幕。举火探路、聆听回声、拓印石刻、为香炉续香、写愿放灯，都会带你走进不同的记忆。有些地方需要仔细寻找，也有些时刻可以停下来，听他把话说完。

- **游览模式**：关键线索会有提示，适合想完整体验故事的玩家。
- **探案模式**：需要从对白中辨认线索，错误判断会消耗心神。

电脑和手机浏览器均可游玩。手机横屏更方便观察完整场景；声音可以在右上角单独调整。进度自动保存在当前浏览器中，重新打开后可以继续；存档不会自动同步到其他设备，清除网站数据也会清除存档。

## 关于这个项目

本项目独立开发，使用 HTML、CSS 和 JavaScript 实现。故事以历史人物和汉阙文化为背景，包含文学演绎；游戏美术为剧情创作的场景与人物画面。
